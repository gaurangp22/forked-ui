# Forked UI

Forked UI is a reusable component library inspired by modern design systems like shadcn/ui, built to help developers quickly build clean, consistent, and scalable user interfaces.

## 🚀 Live Demo
https://forked-ui.vercel.app/

## ✨ Features
- Reusable UI components
- Clean and modern design system
- Easy integration into existing projects
- Fully responsive components
- Scalable and modular architecture
- Developer-friendly structure
